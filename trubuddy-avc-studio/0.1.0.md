# TruBuddy AVC Studio 0.1.0

Released 6 October 2026. First Windows x64 desktop release.

## What's included

- A Windows installer with its own Node runtime, SQLite storage, image/PDF tools and comic Player. Studio starts its local server and background worker automatically.
- Resumable first-run setup, optional Codex account connection and ElevenLabs voice setup, and a replayable comic-editing tutorial.
- Settings for tool checks, Codex installation and repair, account usage, encrypted voice credentials, worker restart and project-folder access.
- English and Hindi comic editions, artwork import, AI extraction proposals with manual review, character management, voice takes, camera timing, background music and sound effects.
- A responsive editor with page and vertical layouts, a dialogue timeline, guided workflow states, local project storage and AVC ZIP export.
- Packaging checks that exclude environment files, local projects, test artifacts and previous build output from the installer.

## Install or update

Download `TruBuddy-AVC-Studio-0.1.0-x64-Setup.exe` from the [GitHub release](https://github.com/NitishMPD/Redtree-public/releases/tag/trubuddy-avc-studio-v0.1.0) and run it. The installer supports a per-user installation and a choice of installation folder. Node and npm do not need to be installed separately.

For later updates, close Studio and run the newer installer. Projects are stored separately in the application-data folder and retained during uninstall. Back up the complete project folder with Studio closed before updating. Automatic updates are not configured.

`SHA256SUMS.txt` contains the installer checksum. This release is unsigned, so Windows may display an unknown-publisher or SmartScreen prompt.

## Current limits

- Windows x64 only.
- Desktop reader links work on the local computer. Share an exported AVC ZIP or use a hosted workspace for public reader links.
- Codex analysis and ElevenLabs speech require internet access and the respective account or API key. Manual editing and imported sound work without either connection.
- Signing, installation on a clean Windows machine, and live paid-provider workflows have not been validated for this release.
