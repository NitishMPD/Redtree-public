# TruBuddy AVC Studio 0.1.2

Released 6 October 2026.

## What's changed

- Added a custom Windows title bar with the installed version, update controls, Settings and theme switch. Minimise, maximise and close remain native Windows controls.
- Made light the default theme and refined the dark palette. Improved editor spacing, readable controls and layouts for shorter windows.
- Compacted first-run setup so checks and Continue fit the minimum desktop window.
- Reworked the sample tutorial to spotlight one editable control at a time, with Next/Back, Escape dismissal and keyboard access. Replay tutorial restarts the guide without resetting sample edits.
- Added panel docking grips, visible resize dividers, keyboard resizing and double-click width reset. Dock preferences persist separately from comic content. Long dialogue stays within its inspector column.
- Added Auto Time, enabled by default, plus dialogue start, duration and pause controls. Select/reorder and Trim/move tools support edge handles and keyboard duration adjustments.
- Ripple timing shifts following dialogue and later sound/markers; manual timing keeps later placement and prevents overlaps. Playback respects authored gaps and duration overrides while retaining valid audio takes.

## Install or update

Use the update control in the title bar or **Settings → App updates** in 0.1.1, then choose **Download update** and **Restart & install**. You can also download [TruBuddy-AVC-Studio-0.1.2-x64-Setup.exe](https://github.com/NitishMPD/Redtree-public/releases/download/trubuddy-avc-studio-v0.1.2/TruBuddy-AVC-Studio-0.1.2-x64-Setup.exe) from the [GitHub release](https://github.com/NitishMPD/Redtree-public/releases/tag/trubuddy-avc-studio-v0.1.2).

The 0.1.0 installer has no updater; install 0.1.2 manually. Close Studio before running the installer. Projects and settings remain in the application's user-data folder. Back up the complete project folder with Studio closed before updating.

The release includes the installer, blockmap, `latest.yml` and `SHA256SUMS.txt`. The installer is unsigned, so Windows may display an unknown-publisher or SmartScreen prompt.

## Validation and limits

The production build, native media/SQLite/storage probes, lint and all 116 unit/integration tests passed, including cue timing and updater coverage. The packaged app passed smoke checks for setup at the minimum window size, tutorial interaction, protected APIs, restart persistence and a live update check. Installation on a clean Windows machine, an installed older version upgrading through the updater, and live paid-provider workflows remain untested for this release.

Windows x64 only. Desktop reader links work on the local computer; share an AVC ZIP or use a hosted workspace for public reader links.
