# TruBuddy AVC Studio 0.1.1

Released 6 October 2026.

## What's changed

- Added in-app Windows updates. Studio checks at startup and every six hours; you can also check from Settings or the Studio menu.
- Added release-note links, download progress and retry controls. Download an update when ready, then choose **Restart & install** separately. Closing Studio does not install a pending update.
- Added restart checks for active analysis/voice jobs, tool installation, edits, uploads and saves. Studio warns before discarding unsaved edits and stops its local services before starting the installer.
- Update discovery uses only stable TruBuddy release tags in the shared repository. Downloads use the selected version's feed and validate the installer name, version and checksum.
- Added version-specific update metadata and a bundled updater to the Windows package.

## Install or update

Download [TruBuddy-AVC-Studio-0.1.1-x64-Setup.exe](https://github.com/NitishMPD/Redtree-public/releases/download/trubuddy-avc-studio-v0.1.1/TruBuddy-AVC-Studio-0.1.1-x64-Setup.exe) from the [GitHub release](https://github.com/NitishMPD/Redtree-public/releases/tag/trubuddy-avc-studio-v0.1.1).

**If you have 0.1.0, install 0.1.1 manually once.** The 0.1.0 installer has no updater. Versions starting with 0.1.1 can download later releases inside Studio.

Close Studio before running the installer. Projects and settings stay in the application's user-data folder. Back up the complete project folder with Studio closed before updating. Node and npm do not need to be installed separately.

This release includes the installer, its blockmap, `latest.yml` for in-app updates and `SHA256SUMS.txt`. The installer is unsigned, so Windows may display an unknown-publisher or SmartScreen prompt.

## Validation and limits

The production build, bundled media/SQLite/storage probes, lint and all 109 unit/integration tests passed. A smoke test of the packaged executable passed setup, the tutorial, protected APIs, restart persistence, a live update check, and simulated download/restart controls. Updater tests cover discovery, metadata validation and restart readiness. Installation on a clean Windows machine, an installed older version upgrading through the updater, and live paid-provider workflows remain untested for this release.

Windows x64 only. Desktop reader links work on the local computer; share an AVC ZIP or use a hosted workspace for public reader links.
