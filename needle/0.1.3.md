# Needle Desktop 0.1.3

This update adds Local OpenCode support for Muse Spark 1.3 Contributor Free. Connect Local OpenCode in Settings, then choose **Muse Spark 1.3 Free** (`opencode/muse-spark-1.3-contributor-free`). Needle uses the installed OpenCode CLI and its existing login. Model access follows your OpenCode account.

Needle now keeps the desktop app's local origin stable between launches. If an earlier version saved projects under different local ports, this update finds and merges those records without deleting the old databases.

The Style Tuner also has four editable generation-glow colors shared by desktop and web.
