# Needle Desktop 0.1.0

First Windows desktop release. The installer bundles Needle's interface and runs its local API bridge on a loopback-only port.

- Uses the installed Codex CLI and OpenCode CLI with their existing logins.
- Supports the existing provider proxy and web capture paths.
- Checks this repository for newer Needle releases and opens the release page when an update is available.
- Keeps projects in the desktop app's local profile. Export a `.needle` file to move a project from the website.

OpenCode's free models can still return `403 FreeTierError` from the installed OpenCode CLI; the desktop app does not bypass the provider's account restriction. The hosted Needle website cannot launch the OpenCode CLI yet.
