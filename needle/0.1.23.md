# Needle Desktop 0.1.23

Needle adds first-run desktop setup for its development tools, with install and sign-in guidance in Settings. Live and Design previews can be shared temporarily through Cloudflare, with controls to copy, open or stop a share. This release also improves Figma image references, canvas annotations and frame controls, and local preview serving.

Needle can download this release from 0.1.14 through its in-app updater.

The production build and TypeScript check passed. Automated tests were not run for this release.
