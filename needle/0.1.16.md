# Needle Desktop 0.1.16

Live now includes a Pages panel that lists pages across project and worktree copies, with copy and branch labels, search, and direct navigation back to each page's canvas frame. The composer has separate controls for editing the current page or creating a new page, and for targeting the current project or a project copy. Creation requests use the selected page as context, create a separate canvas frame and report when the new route is not ready.

This release also refines Live design editing and frame references. Needle can download this release from 0.1.14 through its in-app updater.

The production build and TypeScript check passed. Automated tests were not run for this release.
