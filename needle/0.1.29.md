# Needle Desktop 0.1.29

Codex account controls now live in Live's header menu, where you can review the signed-in account and usage limits. Needle adds persistent local account profiles, account switching, model discovery, quota refresh and streamed usage updates while keeping credentials outside project and browser data.

Skill mentions now stay highlighted in sent messages, including longer conversations. Live also aligns the project switcher and frame controls with the workspace header and composer.

Needle can download this release from 0.1.14 through its in-app updater.

The production build and TypeScript check passed.
