# Needle Desktop 0.1.7

Live mode updates:

- **Start from scratch:** Create a Vite + React or Next.js + Tailwind project and have an agent build an idea as one to four directions.
- **Design systems:** Extract a project's colours, type, spacing and components, load presets, and mention a system in prompts.
- **Edit this page:** Change a project's own page in place, with steps, approvals, diffs and exact undo.
- **Ship the chosen version:** Merge into your branch or keep it as a named feature branch.
- **Approval modes:** Choose Supervised, Auto-accept edits, Auto or Full access for Codex, Claude Code and OpenCode.
- **Model and project controls:** The Claude Code picker lists models available to your account. The directions picker and effort chips are clearer, and the project activity popover shows recent work.
