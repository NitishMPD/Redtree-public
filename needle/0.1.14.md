# Needle Desktop 0.1.14

This release introduces in-app Windows updates. Needle can check for a newer desktop release, download it with progress, and install it when you explicitly choose to restart. It protects active work and asks before discarding unsaved edits. Existing installations through 0.1.13 need to install 0.1.14 manually once; later releases can update inside the app.

Live also adds multi-frame selection and removal controls, an optional Follow cursor view for Progressive design, and several canvas and import refinements. About now includes a Check for updates action.

All 685 tests passed. The installer includes the update runtime and matching update metadata. An installed-app update from 0.1.14 to a later release has not yet been exercised.
