# Needle Desktop 0.1.8

This update refines Live mode's project workflow:

- Start or stop a connected project's app from the Live home screen, with its current status shown there.
- Create a Vite + React or Next.js + Tailwind project from scratch and send an initial request to an agent.
- Load a design system into the current project, mention it by name in a prompt, and review its colours, type, spacing and radii.
- Edit a project's own page with the usual approval, diff and undo controls. Keep a chosen direction by merging it or saving a named branch.
- Remember each project's direction count and show the active model effort and project activity more clearly.
