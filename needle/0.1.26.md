# Needle Desktop 0.1.26

Live now supports separate chats for each project, with independent history and agent context. The Pages panel can rename static routes directly in source, then update the existing canvas frame, saved page records and chat references together. Changes can be undone; unsupported routes and conflicts are reported before edits are applied.

Needle can download this release from 0.1.14 through its in-app updater.

The production build and TypeScript check passed. Automated tests were not run for this release.
