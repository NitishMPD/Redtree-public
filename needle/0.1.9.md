# Needle Desktop 0.1.9

This update improves Live mode's agent conversations:

- Long OpenCode turns can run beyond the previous five-minute response timeout.
- If an agent turn fails, the next request starts a fresh session instead of reusing a failed one.
- Switching agents or models in the composer now takes effect on the next message. When changing providers, the new agent is told to inspect the earlier changes before editing.
- Selecting a version frame opens its conversation only when the composer had focus, so browsing frames no longer opens the chat unexpectedly.
