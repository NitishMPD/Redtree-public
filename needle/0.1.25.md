# Needle Desktop 0.1.25

Live now guides you through setting a Git author identity for the selected project and signing in to GitHub through Git Credential Manager. Renaming a page route updates its existing canvas frame and related page references after the source change succeeds; failed or interrupted changes leave the current route intact, and undo restores both source and route records.

Needle can download this release from 0.1.14 through its in-app updater.

The production build and TypeScript check passed. Automated tests were not run for this release.
