# Needle Desktop 0.1.15

This release expands Live Design edit. The inspector now has clearer Layers and Changes views, element hover highlighting, and direct text editing on the page. Wheel gestures over an editable page pan or zoom the Live canvas. It also includes Live frame references, queued and steerable AI messages, and the desktop fix for opening Live previews in your browser.

Needle can download this release from 0.1.14 through its in-app updater. A full installed-app update and relaunch has not yet been verified.

All 732 tests passed. The Windows installer and update metadata were built from Needle 0.1.15.
