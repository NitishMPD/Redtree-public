# Needle Desktop 0.1.17

Live projects now support separate project tabs and remember each workspace's open views. Website import can capture a public site into a local project, then open it in Live for review and editing. The desktop Live shell also adds website capture support, project capability checks, and refinements to approval and design-edit controls.

Needle can download this release from 0.1.14 through its in-app updater.

The production build and TypeScript check passed. Automated tests were not run for this release.
