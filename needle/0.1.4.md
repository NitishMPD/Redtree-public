# Needle Desktop 0.1.4

This release fixes Needle closing during startup after version 0.1.3's storage migration. The migration's hidden windows can now close without quitting the app before its main window opens.

It also skips migration windows once all older local origins have been processed. Projects and settings remain in the existing local profile.

Install this version if 0.1.3 appears to do nothing when opened. It includes the Muse Spark 1.3 Contributor Free support from 0.1.3.
