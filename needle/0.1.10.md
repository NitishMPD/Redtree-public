# Needle Desktop 0.1.10

This release adds Figma references to Live projects:

- Import a local `.fig` file, a Figma Design link, or an export from the included read-only Figma plugin. Browse frames, previews, hierarchy, and extracted image assets.
- Select imported frames in a Live prompt so an agent can use their design context. Compare the generated page with a reference frame, and review import diagnostics when some content cannot be rendered.
- Attach images to Live prompts by choosing files or pasting them. Codex, OpenCode, and Claude turns receive the attachments.
- Set optional local paths for the Codex and OpenCode CLIs in provider settings or Live agent selection.

The desktop package includes the renderer needed for local `.fig` previews. All 563 tests passed for this build.
