# Needle Desktop 0.1.27

Needle now includes a Skills manager in Setup for Codex, Claude Code and OpenCode, with curated frontend guidance and install status. In Live, type `$` to find installed skills and insert mentions; recognized skill names appear as inline pills.

Live agent turns now handle long Codex conversation resumes, stream Claude's intermediate output reliably, and explain the Progressive operation protocol clearly. Desktop setup and packaged skills now work together.

Needle can download this release from 0.1.14 through its in-app updater.

The production build and TypeScript check passed. Automated tests were not run for this release.
