# Needle Desktop 0.1.18

Live can now generate multiple named pages in one project or shared project copy, each with its own route and canvas frame. When a request needs page names, Needle asks first; native Codex questions appear as answer cards with choices or free text. Follow mode now fits and centers the full page, shows growing draft content, and releases camera control when you pan or zoom manually.

Needle can download this release from 0.1.14 through its in-app updater.

The production build and TypeScript check passed. Automated tests were not run for this release.
