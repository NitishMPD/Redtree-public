# Needle Desktop 0.1.30

Live canvas updates are more focused: progressive drafts and operations are scoped to the active page, unchanged surface nodes are reused, and iframe raster refreshes prioritize visible frames. Frame previews restore their original sizing when work completes or tabs change.

Source control keeps bulk Stage and Discard actions visible, groups generated commit drafts around readable source changes, and adds a staged-change overview with file, line and binary totals. The selected-frame toolbar now enters without briefly overflowing its container.

Needle can download this release from 0.1.14 through its in-app updater.

The production build and TypeScript check passed. Targeted canvas, raster, source-control, commit-draft and toolbar tests passed before packaging.
