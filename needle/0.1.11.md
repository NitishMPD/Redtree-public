# Needle Desktop 0.1.11

This update improves Live projects and Figma imports:

- Figma imports now show progress and clearer diagnostics for frames or layers that cannot be rendered.
- Live prompts can mention project or version files. Sent annotations can reopen and highlight their target elements.
- A dedicated interactive preview offers device sizes, rotation, and optional device frames. New keyboard shortcuts make it easier to annotate, point, switch views, and preview.
- Live activity messages and direct-edit conversations are easier to read.

The Windows packaging command now stages Electron outside the repository, avoiding the folder lock that caused the previous build to fail. All 568 tests passed.
