# Needle Desktop 0.1.20

Live now edits several selected pages together while preserving their existing routes and keeping each page in its own project frame. Website import shows persistent per-page capture and conversion progress, including local route checks and useful failure details. Local web development can also use the desktop capture worker.

Needle can download this release from 0.1.14 through its in-app updater.

The production build and TypeScript check passed. Automated tests were not run for this release.
