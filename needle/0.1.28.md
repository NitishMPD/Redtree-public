# Needle Desktop 0.1.28

Live now includes page usage search with file, line and code details, plus a Delete page action that checks the selected project and restores source and frames through Undo. Git staging and unstaging can continue during active project and copy edits while checkout and other Git-write guards remain in place. Skill mention pills are better aligned in the composer.

Needle can download this release from 0.1.14 through its in-app updater.

The production build and TypeScript check passed. Targeted page usage, menu, chat and deletion tests passed before packaging.
