# Needle Desktop 0.1.21

Website import now recovers more gracefully when pages stall during loading. It can keep partial captures with screenshots and discovered links, while empty or uncommitted pages still report a failure. Import progress and reminders persist when you close the dialog, and you can dismiss a reminder without losing recent captures or their evidence.

Needle can download this release from 0.1.14 through its in-app updater.

The production build and TypeScript check passed. Automated tests were not run for this release.
