# Needle Desktop 0.1.6

Live mode lets you connect a local JavaScript repository and design on a canvas of its real pages. Explore one to four directions with Codex, Claude Code or OpenCode in isolated Git worktrees. See each agent step, approve commands, annotate elements, undo changes, and keep a result as a branch or merge it. The Live canvas also has keyboard shortcuts.
