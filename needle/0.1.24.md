# Needle Desktop 0.1.24

Live adds controls to review and discard project changes, and improves Windows preview reliability. New agent permission and clarification requests now open the right project conversation for you to respond to. Temporary sharing setup and failure details are clearer, and installed sharing includes the connector helper it needs.

Needle can download this release from 0.1.14 through its in-app updater.

The production build and TypeScript check passed. Automated tests were not run for this release.
