# Needle Desktop 0.1.19

Live project tabs now stay mounted when you switch projects, preserving each workspace's canvas and preview state. Multi-page composer controls show the planned page names, page references handle newly created routes, and the Queue/Steer choice is easier to switch while a response is running. Live also avoids starting a duplicate development server for a project that is already running.

Needle can download this release from 0.1.14 through its in-app updater.

The production build and TypeScript check passed. Automated tests were not run for this release.
