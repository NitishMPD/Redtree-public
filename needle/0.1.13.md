# Needle Desktop 0.1.13

This release adds **Progressive design** to Live projects. Turn it on from the chat composer to watch an agent draw versioned design steps on the canvas while it works. It is off by default and remembered per project. If a step cannot be applied or the turn fails, Needle keeps a labelled draft with Retry and Return to app actions.

New pages now persist after a generated version is merged. The new frame appears in the project, and the Pages panel and composer route lists refresh. Reopening the project restores frames that earlier merges may have missed.

All 633 unit tests passed for this build. The Progressive design workflow was also checked with eight browser tests against the local framing proxy.
