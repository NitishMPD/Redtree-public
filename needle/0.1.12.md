# Needle Desktop 0.1.12

This release expands preview and Live project controls:

- Open a standalone Device preview from Home to inspect a website or local HTML at responsive sizes, with browser chrome, rotation, zoom, and optional phone cutouts.
- Use the same device frames in Live preview, with Fit and 100% viewing. Mobile previews hide desktop scrollbar tracks while keeping scrolling available.
- Review and manage Live project Git state from the workspace.
- Saved design systems now show their resolved colors and mode values in the picker, preview, and agent reference.

All 575 tests passed for this build.
